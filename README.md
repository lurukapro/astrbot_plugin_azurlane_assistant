# ⚓ AstrBot 碧蓝航线助手 (AzurLane Assistant)

一个为 **AstrBot** 设计的碧蓝航线数据查询插件。支持**账号绑定**，通过 Bilibili 小程序接口查询指挥官数据、建造记录以及服务器 ID 转换。

**亮点**：查询结果为**小程序同款 UI 卡片图**（官方素材还原）；建造记录长图（每100条一张，多张自动打包**合并转发**）；支持范围查询（`azb 100-200`）；**指令免空格**（`azbind1347750182秋季旅行` 也能识别）；**UID 自动识别服务器**（40服并发探测+新服自动登记）。

---

## ✨ 功能特性

* **小程序同款 UI 卡片图**：`az` 输出「我的」页风格指挥官卡片，`azb` 输出「建造记录」页风格列表卡片，官方背景纹理 + 面板插画完整还原。
* **UID 自动识别服务器**：`az <UID>` 不填服务器也能查——并发探测全部服务器（含预留新服编号段），发现新服自动登记，无需改代码。
* **账号绑定**：绑定一次 UID + 服务器，之后 `az` / `azb` 免输入直查；绑定服务器也可省略自动识别。
* **指挥官信息查询**：图鉴收集率、主线进度、石油/物资/食量、委托/科研进度、信标/演习/困难关卡/每日挑战待办。
* **好友查询**：`az @某人` 直接查看群友绑定的账号信息（@机器人唤醒不会误判）。
* **建造记录查询**：默认 50 条、可指定数量或范围（`azb 100-200`）+ 舰池统计；超过 100 条自动分张并**打包成一条合并转发消息**；超过上限自动转**合并转发文本**。
* **服务器转换**：服务器中文名与数字 ID 互查（如 `120` ↔ `秋季旅行`），`azs` 可列出全部服务器（含动态发现的新服）。
* **懒人指令**：空格可省略、支持全角符号，`azbind1347750182秋季旅行`、`azb50`、`azs秋季旅行` 都能识别。
* **本地渲染优先**：`auto` 策略下优先用本地 playwright 渲染（不依赖远程 t2i 服务），失败自动走远程，再失败回退文本。
* **查询缓存与冷却**：玩家数据 60 秒、建造数据 5 分钟缓存，防刷接口。
* **风控友好**：页间限速、空数据自动重试、明确的风控提示。

## ⚙️ 安装与配置

### 1. 放置插件

将插件文件夹 `astrbot_plugin_azurlane_assistant` 放入 `data/plugins/` 目录（或通过 WebUI 安装 zip）。

### 2. 安装依赖

AstrBot 安装/更新插件时会**自动安装** `requirements.txt` 里的依赖；若自动安装失败，手动执行：

```bash
pip install httpx jinja2
```

| 依赖 | 用途 | 说明 |
| --- | --- | --- |
| `httpx` | 调用 bilibili 小程序接口 | 必需 |
| `jinja2` | 渲染 UI 卡片模板 | AstrBot 核心通常已自带 |
| `playwright` | 本地渲染卡片图片（推荐） | 需再执行一次 `playwright install chromium` |

**图片渲染说明**（`render_mode = image` 时）：

- `render_strategy = auto`（默认）：本地 playwright 优先，失败自动走 AstrBot 的远程 t2i 服务，再失败回退文本
- 使用本地渲染前需安装浏览器内核：`pip install playwright` 然后 `playwright install chromium`
- 若不想装 playwright，可把 `render_strategy` 设为 `remote`（依赖远程 t2i 服务可用性）

### 3. 插件配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `render_mode` | `image` | 输出模式：`image`=UI 卡片图，`text`=纯文本 |
| `render_strategy` | `auto` | 渲染方式：`auto`/`local`/`remote` |
| `request_timeout` | 15 | 接口请求超时（秒） |
| `cooldown_seconds` | 5 | 同一用户查询冷却（秒），0 关闭 |
| `cache_seconds` | 60 | 玩家数据缓存时长（秒）；建造数据固定缓存 5 分钟 |
| `max_build_count` | 500 | 建造记录单次最大拉取条数（接口上限约 500） |

### 4. 数据文件

- 绑定关系：`data/plugin_data/azurlane_assistant/bindings.json`
- UID 所在服缓存：`data/plugin_data/azurlane_assistant/uid_servers.json`
- 动态发现的新服：`data/plugin_data/azurlane_assistant/dynamic_servers.json`

重启、更新插件均不会丢失。

## 🎮 指令说明

### 🔗 绑定相关

| 指令 | 格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| **`/az bind`** | `/az bind <UID> [服务器]` | `/az bind 13xxxx 120` | 绑定账号（服务器可省略自动识别） |
| **`/az unbind`** | `/az unbind` | | 解除自己的绑定 |
| **`/az my`** | `/az my` | | 查看自己当前的绑定信息 |

### 👤 查询相关

| 指令 | 格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| **`/az`** | `/az` | | 查询**自己**绑定的账号（需先绑定） |
| **`/az`** | `/az <UID> [服务器]` | `/az 13xxxx 120` | 查询指定指挥官（服务器可自动识别） |
| **`/az`** | `/az @某人` | | 查询对方绑定的账号 |
| **`/azb`** | `/azb [数量]` | `/azb 50` | 查询自己绑定的建造记录（默认 50 条） |
| **`/azb`** | `/azb 100-200` | | 查询第 100~200 条记录 |
| **`/azb`** | `/azb <UID> [服务器] [数量]` | `/azb 13xxxx 120 50` | 查询指定指挥官建造记录 |
| **`/azb`** | `/azb @某人 [数量]` | | 查询对方绑定账号的建造记录 |
| **`/azs`** | `/azs <名称或ID>` | `/azs 秋季旅行` | 查询服务器对应的 ID 或名称 |
| **`/azs`** | `/azs` | | 列出全部服务器 |
| **`/az help`** | | | 查看帮助菜单 |

> **提示**：
> - **懒人模式**：空格可省略、支持全角空格/逗号分隔，如 `azbind1347750182秋季旅行`、`azb50`、`azs秋季旅行`。
> - `<服务器>` 支持中文简称（`秋季`）、全名（`秋季旅行`、`官网20`）或数字 ID（`120`）。
> - 绑定后，只输 UID 不输服务器时自动使用绑定的服务器；未绑定则自动识别服务器。
> - `azb` 后跟 6 位以上数字按 UID 解析，6 位以内按查询条数解析。
> - 建造接口最多保留**最近 500 条**记录，且数据有约 **1 小时延迟**（接口侧限制）。

## ❓ 常见问题

**Q: 输入指令后机器人完全没反应？**

1. **重启机器人**：修改/更新插件后请完全重启 AstrBot 进程。
2. **检查前缀**：确保指令带有机器人设置的命令前缀（如 `/`），或使用 @机器人唤醒。
3. **参数冲突**：检查是否有其他插件占用了 `az` 开头的指令。

**Q: 卡片图片发送失败或显示为文本？**

* 本地渲染需要 playwright + chromium（见依赖说明）；渲染失败时插件会**自动回退**：本地→远程→文本，功能不中断。

**Q: azb 提示"接口返回空数据"？**

* 大概率触发了接口风控（查询太频繁），通常几十分钟自动恢复；插件已内置页间限速、自动重试与 5 分钟缓存来尽量避免。

**Q: 绑定信息会泄露吗？**

* 绑定关系保存在你自己服务器上的本地文件中，不涉及任何微信凭证；查询数据均为游戏公开信息。
