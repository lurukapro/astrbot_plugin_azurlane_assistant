# ⚓碧蓝航线助手 (AzurLane Assistant)

这是一个轻量级的《碧蓝航线》数据查询插件，使用碧蓝航线小程序接口。

## ✨ 功能特性

* 👤 **用户信息查询**：获取等级、舰队、资源储备（物资/石油/存粮）、主线进度及实时委托/科研/演习状态。
* 🏗️ **建造记录大批量查询**：支持最高 **500 条**建造记录拉取，20 条以上自动转为**合并转发窗**，按 100 条/组分段展示。
* 📡 **服务器智能匹配/转换**：支持服务器名称与 ID 的互转（如输入 `秋季旅行` 自动匹配 `120`）。
* ⚙️ **配置化 Cookie**：支持在 AstrBot 管理面板填写 Cookie 以获取详细数据。

## 🚀 安装指南

1. **放置插件**：
将插件文件夹 `azurlane_assistant` 放入 `data/plugins/` 目录。
2. **安装依赖**：
在 AstrBot 控制台执行：
```bash
pip install httpx

```


3. **配置 Cookie**：
在 AstrBot 管理面板 -> 插件配置中填入bilibili网页F12获取的 `Cookie`（不填没影响）。

## 🎮 使用指令(只能官服用，游戏内uid，不是b站uid)

### 1. 服务器查询/转换

**指令**：`az <名称/ID>` 或 `azs <名称/ID>`

**示例**：

* `az 秋季旅行` -> 输出 `官网20服-秋季旅行 120`
* `azs 120` -> 输出 `官网20服-秋季旅行 120`

### 2. 玩家详情查询

**指令**：`az <UID> <服务器名称/ID>`

**示例**：

* `az 13xxxxx2 秋季旅行`
* `az 13xxxxx2 秋季`
* `az 670xxxxxx 210`

### 3. 建造记录查询

**指令**：`azb <UID> <服务器名称/ID> [展示数量]`

**说明**：展示数量上限为 500。超过 20 条将以转发窗形式发送。

**示例**：

* `azb 134xxxx 120 10` (直接发送文本)
* `azb 134xxxx 120 100` (合并转发窗发送)
