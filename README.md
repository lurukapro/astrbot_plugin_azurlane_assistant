# ⚓ AstrBot 碧蓝航线助手 (AzurLane Assistant)

一个为 **AstrBot** 设计的轻量级碧蓝航线数据查询插件。支持通过 Bilibili 小程序接口查询指挥官数据、建造记录以及服务器 ID 转换。

---

## ✨ 功能特性

* **指挥官信息查询**：一键查看等级、收藏率、资源存量、待办副本。
* **建造记录查询**：支持自定义查询条数，超过 20 条自动转换为**合并转发消息**，避免刷屏。
* **服务器转换**：支持服务器中文名与数字 ID 互查（如 `120` $\leftrightarrow$ `秋季旅行`）。
* **强健的容错性**：针对 AstrBot 参数解析优化，支持纯数字 ID 输入而不报错。

---

## ⚙️ 安装与配置
### 1. 放置插件
将插件文件夹 `azurlane_assistant` 放入 `data/plugins/` 目录。


### 2. 安装依赖

确保你的环境中已安装 `httpx`：

```bash
pip install httpx

```

## 🎮 指令说明

| 指令 | 格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| **`/az`** | `/az help` | `/az help` | 查看本帮助菜单 |
| **`/az`** | `/az <UID> <服务器>` | `/az 13xxxx 120` | 查询指定指挥官详情 |
| **`/azb`** | `/azb <UID> <服务器> [数量]` | `/azb 13xxxx 120 50` | 查询建造记录（默认10条） |
| **`/azs`** | `/azs <名称或ID>` | `/azs 秋季旅行` | 查询服务器对应的 ID 或名称 |

> **提示**：UID是游戏内UID`<服务器>` 参数既可以输入中文（如 `秋季旅行`、`秋季`），也可以直接输入数字 ID（如 `120`）。

---

## ❓ 常见问题

**Q: 输入指令后机器人完全没反应？**

1. **重启机器人**：修改 `main.py` 后，请务必完全关闭 AstrBot 进程再重新启动，以清除指令缓存。
2. **检查前缀**：确保你发送的指令带有机器人设置的命令前缀（如 `/`）。
3. **参数冲突**：检查是否有其他插件占用了 `az` 开头的指令。

**Q: 服务器 ID 怎么看？**

* 使用 `/azs <服务器名>` 即可快速查询。例如 `/azs 莱茵`。
